# Design a video

Start with the audience and the one thing each shot must communicate. Collect lawful visual references with source links and timestamps. Note the specific technique to learn, such as how an action reveals a state change. Use original graphics and footage for implementation.

Define a palette and type hierarchy. For each shot write the starting state, main subject, action, end state and the claim it illustrates. Identify the easiest shot to misread and include it in the sample. Use the project's approved renderer and sample duration. Pause when the renderer or permissions are unavailable.

Ask a viewer unconnected with production to explain the action at normal speed. If the video is meant to work silently, ask for a silent interpretation or attempt. Keep the review and authorized approval with the sample version. After the sample passes the project's design gate, the project lead can assign the full output. Local revisions of an existing complete piece follow the lead's agreed scope and are reviewed on the new full version.
