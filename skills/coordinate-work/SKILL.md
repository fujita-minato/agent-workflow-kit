# Coordinate work

Read the latest project handoff and the actual state before assigning a task. Record the owner's decision, responsible project lead, requested version, inputs, deliverable, acceptance evidence, writable scope and time budget. Split by independently verifiable work with one writer per artifact.

Use project leads for tradeoffs and review. Give research, tests, batch changes and scoped implementation to a worker. Provide the input and expected evidence in the brief. Route cross-project feedback with the affected version, observation and a check the receiving team can reproduce. Record receipt separately from sending.

Report outcomes and decisions. Keep the queue explicit about work that can proceed, work in progress and work waiting for the owner. Use the delivery gate for revised artifacts.

Keep recurring owner corrections with an identifier, an expected behavior and a check that fails for the known bad case. Use the actual project verification entry point. Give reviewers the applicable identifiers and keep any historical gaps visible.
