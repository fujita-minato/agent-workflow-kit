# Deliver a revision

Keep working versions and review notes in the team workspace. Use the project's authorized design and sample gates when first producing or redesigning an artifact.

For a finished candidate, collect a content verdict and, for a film, a separate visual verdict. Use the same candidate hash in both reviews. Validate the [review record](references/review-record.md) using the installed checker. Send one link to the revised full artifact once it passes. Use a short project card for the decision, what changed, verification and any action only the owner can take.

If a review fails, return it to the single writer with the exact evidence. If an owner decision is needed, describe the decision and its effect. Treat publishing as a separately authorized action.
