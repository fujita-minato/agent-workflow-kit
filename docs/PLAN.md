# Release candidate plan

| Scope | Done when |
| --- | --- |
| Roles and skills | Both runtimes have matching responsibilities, with separate coordination, research, execution and review. |
| Local install | A temporary empty target can install either or both runtimes twice. A conflicting existing file is preserved. |
| Delivery | A finished example passes. A changed artifact, a failed required review or a reference outside the bundle is rejected. |
| Privacy | The source tree and intended Git contents pass the privacy scan. Owner reviews the local repository before any external publication. |
